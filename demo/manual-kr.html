소개

Tiptap은 ProseMirror 기반의 헤드리스(headless) 리치 텍스트 에디터입니다. 완전한 커스터마이징이 가능하며, 프레임워크에 독립적으로 사용할 수 있습니다.

주요 특징

  • 헤드리스 아키텍처 - 스타일과 UI를 완전히 제어할 수 있습니다
  • 확장 가능 - 필요한 기능만 선택하여 사용할 수 있습니다
  • 프레임워크 독립적 - Vanilla JS, React, Vue 등 모든 환경에서 사용 가능합니다
  • 협업 지원 - 실시간 협업 기능을 쉽게 구현할 수 있습니다
  • TypeScript 지원 - 완전한 타입 안정성을 제공합니다

브라우저 호환성

Tiptap은 다음 브라우저를 지원합니다:

  • Chrome/Edge (최신 2개 버전)
  • Firefox (최신 2개 버전)
  • Safari (최신 2개 버전)
  • iOS Safari (iOS 13+)
  • Chrome for Android (최신 버전)

빠른 시작

CDN을 통한 설치

가장 빠르게 시작하는 방법은 ESM CDN을 사용하는 것입니다:

<script type="module">
  import { Editor } from 'https://esm.sh/@tiptap/core@3.7.2'
  import StarterKit from 'https://esm.sh/@tiptap/starter-kit@3.7.2'

  // 에디터 생성
  const editor = new Editor({
    element: document.querySelector('#editor'),
    extensions: [StarterKit],
    content: '<p>안녕하세요!</p>'
  })
</script>

첫 번째 에디터

기본 에디터를 생성하는 코드:

import { Editor } from 'https://esm.sh/@tiptap/core@3.7.2'

기본 사용법

에디터 생성

에디터를 생성하려면 Editor 클래스를 인스턴스화합니다:

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit],
  content: '<p>초기 콘텐츠</p>',
  editable: true,
  autofocus: false,
  onUpdate: ({ editor }) => {
    console.log('콘텐츠가 변경되었습니다')
  }
})

콘텐츠 다루기

// HTML 가져오기
const html = editor.getHTML()

// 텍스트만 가져오기
const text = editor.getText()

// 콘텐츠 설정
editor.commands.setContent('<p>새로운 콘텐츠</p>')

// 콘텐츠 추가
editor.commands.insertContent('<p>추가 콘텐츠</p>')

명령어 실행

// 단일 명령어
editor.commands.toggleBold()

// 체이닝 명령어
editor
  .chain()
  .focus()
  .toggleBold()
  .insertContent('굵은 텍스트')
  .run()

// 명령어 실행 가능 여부 확인
const canUndo = editor.can().undo()

Vanilla JavaScript

기본 구현

class MyEditor {
  constructor(element) {
    this.editor = new Editor({
      element: element,
      extensions: [StarterKit],
      content: '<p>시작!</p>'
    })
  }

  getContent() {
    return this.editor.getHTML()
  }

  setContent(html) {
    this.editor.commands.setContent(html)
  }

  destroy() {
    this.editor.destroy()
  }
}

// 사용
const myEditor = new MyEditor(document.querySelector('#editor'))

툴바 만들기

const toolbar = document.querySelector('#toolbar')

const buttons = [
  {
    label: '굵게',
    action: () => editor.chain().focus().toggleBold().run(),
    isActive: () => editor.isActive('bold')
  },
  {
    label: '기울임',
    action: () => editor.chain().focus().toggleItalic().run(),
    isActive: () => editor.isActive('italic')
  }
]

buttons.forEach(btn => {
  const button = document.createElement('button')
  button.textContent = btn.label
  button.onclick = btn.action

  // 활성 상태 업데이트
  editor.on('transaction', () => {
    button.classList.toggle('is-active', btn.isActive())
  })

  toolbar.appendChild(button)
})

jQuery 통합

jQuery 플러그인 패턴

(function($) {
  $.fn.tiptapEditor = function(options) {
    return this.each(function() {
      const editor = new Editor({
        element: this,
        extensions: [StarterKit],
        content: options.content || '<p></p>',
        onUpdate: options.onChange
      })

      $(this).data('editor', editor)
    })
  }
})(jQuery)

// 사용
$('#editor').tiptapEditor({
  content: '<p>안녕하세요!</p>',
  onChange: ({ editor }) => {
    console.log('변경됨')
  }
})

jQuery 이벤트

// 커스텀 이벤트 발생
$('#editor').on('tiptap:update', function(e, editor) {
  console.log('에디터 업데이트')
})

// 에디터에서 이벤트 발생
editor.on('update', ({ editor }) => {
  $('#editor').trigger('tiptap:update', [editor])
})

확장 기능

StarterKit

StarterKit은 가장 일반적인 확장 기능들을 포함합니다:

  • Document
  • Paragraph
  • Text
  • Bold, Italic, Strike, Code
  • Heading (H1-H6)
  • BulletList, OrderedList, ListItem
  • Blockquote
  • CodeBlock
  • HorizontalRule
  • HardBreak
  • Dropcursor
  • Gapcursor
  • History (실행 취소/재실행)

확장 기능 설정

const editor = new Editor({
  extensions: [
    StarterKit.configure({
      heading: {
        levels: [1, 2, 3]
      },
      bulletList: {
        keepMarks: true
      }
    })
  ]
})

명령어

텍스트 포맷팅

editor.commands.toggleBold()      // 굵게
editor.commands.toggleItalic()    // 기울임
editor.commands.toggleStrike()    // 취소선
editor.commands.toggleCode()      // 인라인 코드

제목

editor.commands.toggleHeading({ level: 1 })  // H1
editor.commands.toggleHeading({ level: 2 })  // H2
editor.commands.toggleHeading({ level: 3 })  // H3

목록

editor.commands.toggleBulletList()   // 글머리 기호 목록
editor.commands.toggleOrderedList()  // 번호 매기기 목록

기타

editor.commands.toggleBlockquote()  // 인용문
editor.commands.toggleCodeBlock()   // 코드 블록
editor.commands.setHorizontalRule() // 수평선
editor.commands.setHardBreak()      // 줄바꿈

editor.commands.undo()              // 실행 취소
editor.commands.redo()              // 재실행

editor.commands.selectAll()         // 전체 선택
editor.commands.focus()             // 포커스

이벤트

사용 가능한 이벤트

editor.on('create', ({ editor }) => {
  console.log('에디터 생성됨')
})

editor.on('update', ({ editor }) => {
  console.log('콘텐츠 변경됨')
})

editor.on('selectionUpdate', ({ editor }) => {
  console.log('선택 영역 변경됨')
})

editor.on('transaction', ({ editor, transaction }) => {
  console.log('트랜잭션 발생')
})

editor.on('focus', ({ editor, event }) => {
  console.log('포커스됨')
})

editor.on('blur', ({ editor, event }) => {
  console.log('포커스 해제됨')
})

editor.on('destroy', () => {
  console.log('에디터 파괴됨')
})

API 레퍼런스

Editor 인스턴스 속성

속성 타입 설명
commands Object 명령어 실행
can() Function 명령어 실행 가능 여부 확인
chain() Function 명령어 체이닝
isActive() Function 노드/마크 활성 상태 확인
getHTML() Function HTML 콘텐츠 가져오기
getText() Function 텍스트 콘텐츠 가져오기
isEmpty Boolean 콘텐츠 비어있는지 여부
isEditable Boolean 편집 가능 여부

유용한 메서드

// 편집 모드 전환
editor.setEditable(true)
editor.setEditable(false)

// 포커스 상태 확인
const isFocused = editor.isFocused

// 에디터 파괴
editor.destroy()
