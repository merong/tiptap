기본 에디터

가장 기본적인 Tiptap 에디터 구현입니다. 최소한의 설정으로 에디터를 생성합니다.

코드 예제

// Tiptap 에디터 생성
const { Editor } = window.tiptap
const StarterKit = window.tiptapStarterKit.StarterKit

const editor = new Editor({
  element: document.getElementById('editor'),
  extensions: [StarterKit],
  content: '<p>안녕하세요!</p>'
})

// 콘텐츠 가져오기
const html = editor.getHTML()
console.log(html)

// 콘텐츠 설정
editor.commands.setContent('<p>새로운 내용</p>')

// 에디터 포커스
editor.commands.focus()

// 에디터 파괴
editor.destroy()
